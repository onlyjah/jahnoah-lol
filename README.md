# JahNoah.lol

Astro blog built into static HTML and assets for Cloudflare Pages.

Use Node 22 or later. Run `npm ci` and `npm run dev` to edit locally; `npm run check` validates a complete static build. Markdown and MDX posts live in `src/content/blog/`. Output is `dist/`.

See [the Pages migration instructions](docs/PAGES-MIGRATION.md) for hosting and rollback. This branch prepares the migration; it does not change the existing live host.
